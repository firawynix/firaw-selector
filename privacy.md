# Privacy policy

FirawSelector doesn't collect analytics, account information, browsing history,
or telemetry. Rules and preferences stay on the user's computer.

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

When the user opens a link, FirawSelector passes that link to the browser and
profile selected by the user's local rules. The chosen browser, not
FirawSelector, then contacts the destination. Optional browser extensions send
the current link only to the local FirawSelector application through the
browser's native messaging interface.

Build tools may access package repositories while maintainers create a release.
That build-time activity isn't part of the installed application's behavior.

Report privacy concerns through the
[public issue tracker](https://github.com/firawynix/firaw-selector/issues).
